# 金融学基础：十五章中文译稿

本目录汇集第1至第15章中文 LaTeX 译稿，保留原稿的章节层级、案例、公式、可编辑图表及章末模块。各章文件沿用英文文件名，正文为中文；英文源文件保存在仓库根目录。

## 文件与编译

- `main_zh.tex`：十五章合并编译入口。
- 各章 `.tex`：可单独编辑的中文译稿。
- `finance-textbook-zh.pdf`：此前保存的**前五章**合并 PDF。本次没有重新编译十五章 PDF，请以 `.tex` 源文件及主文件为准。

安装含中文支持及 Fandol 字体的 TeX Live 或 MiKTeX，在本目录运行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main_zh.tex
```

主文件使用 `ctexbook`，包含 `amsmath`、`amssymb`、`booktabs`、`tabularx`、`enumitem`、`makecell`、`tikz`、`pgfplots`、`tcolorbox`、`fancyhdr` 和 `hyperref` 等宏包。图表保留为原有 LaTeX/TikZ/PGFPlots 代码。
